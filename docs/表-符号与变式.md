## 一、总公式

根只有一句：**不付就散**。由此每一步都要付账；一次付账就是「一拍」；一拍走六步。

**六步求值**（顺序不能换，每步只用前面已定义的符号）：

1. `E_in = min{ D·(A/δ)·ΔC, ε·M, S }` —— **进项**：输运、转化、供给三路取最紧的那一路。
2. `净日常 = E_in − C_m − L` —— 这一拍扣掉维持与损耗还剩多少。
3. `净恢复 = 净日常 − E_restore` —— 再扣掉把损伤补回来的账。
4. `R = step(净恢复)` —— **付得起是 1，付不起是 0**；`R = 0` 在这里就短路返回，后面不再算。
5. `Λ = R · min{ 净日常/E_in, 1 − τ/T_ref }` —— 存续量：能量余量与时间余量，取更紧的那一项。
6. `Λ > 0` —— **活着**。

**总的递归式**（一拍接一拍，不是式子内部再算自己）：

- `E_restore(n) = E_restore(n−1)·(1 − η) + E_damage(n)`，初值 `E_restore(0) = 0`。
- **活着 ⟺ 对所有 `n`：`Λ(n) > 0`**。

**无量纲化**（比较不同域之前先做这一步）：

- `x = C_m/E_in`、`l = L/E_in`、`e = E_restore/E_in`、`θ = τ/T_ref`
- 于是 `Λ = R · min{ 1 − x − l, 1 − θ }`
- **能比的条件：同一个无量纲量 ＋ 同一档的取数口径**；换口径去看同一个数，那不是比，是换题。

## 二、它从哪来：从「不付就散」到六步

**起点不是公式，是一句没有前件的话：不付就散。**

它没有前件——任何有结构的东西，停止付账就会散开。**公式是它的第一次落地**：

> `E_in = ΔG_s + Q`（`Q > 0`）

意思只有一句：**进来的一份能量，要同时盖住「维持形状的价钱」和「回不来的损耗」**。

从这条往下长，四处延伸，都只加「这一步必须付的那笔」，不加假定：

| 延伸 | 加了什么 | 长成哪一步 |
|---|---|---|
| ① **把「一次」变成「一拍」** | 时间尺度：进项、维持、损耗都按拍计 | `净日常 = E_in − C_m − L` |
| ② **把「补回来的账」放进来** | 损伤要补，补的钱单独记 | `净恢复 = 净日常 − E_restore` |
| ③ **放一个开关** | 付不起就短路，不再往下算 | `R = step(净恢复)` |
| ④ **记「这一拍花了多久」** | 时间也有余量 | `1 − τ/T_ref` |

把 ③④ 与 ② 合起来，就是第⑤步的 `Λ`；`Λ > 0` 就是活着。

**这四处延伸没有一处是“假定”**——每一步都是「不付就散」逼出来的；把它们删掉任一条，整条链就断。

### 示例：拿「人」走一遍（数来自账 §107／§108）

| 步 | 取数 | 结果 |
|---|---|---|
| ① 进项 | `E_in = 100.7 W` | — |
| ② 净日常 | `100.7 − 65.6 − 10.1` | **25.0 W** |
| ③ 净恢复 | `25.0 − E_restore`（当期 `E_restore ≈ 0`） | **25.0 W** |
| ④ 开关 | `25.0 > 0` | **`R = 1`** |
| ⑤ 存续量 | `min{ 25.0/100.7, 1 − 0.25 } = min{ 0.248, 0.750 }` | **`Λ = 0.248`** |
| ⑥ 判 | `0.248 > 0` | **活着** |

**瓶颈是能量余量**（0.248 < 0.750）——所以这一档要抬，抬的是进项或维持，不是时间。

## 三、各档最简式（同一个式子，是整棵树，换档只换「套哪几项」）

| 档 | 套哪几项 | 这一档写出来是什么 |
|---|---|---|
| **生物** | 六步全走 | `Λ = R·min{净日常/E_in, 1−τ/T_ref}`，按最紧那项定指数（1/3、2/3、0.75） |
| **恒星** | 无 `κ`、`τ/T_ref → 0`、`E_in` 取存量 | `Λ = 1 − Q/L`（燃料对光度） |
| **化学** | `τ/T_ref → 0`、`R = 1` | `Λ = 1 − (C_m+L)/E_in`（即 `ΔG` 判据） |
| **死物** | `ε = 0` → 无进项 | `Λ < 0`（只散不存） |
| **数学** | 维持项全用不到 | **只算个数**：一个方程，条件成立即在 |

**不是“退化”**：树没缩小，只是那一枝用不到那些项。

## 六、怎么用这三步 + 边界

1. **先看第一节**：要算哪六步、递归怎么接；
2. **再看第二节**：这些式子是从哪长出来的、别人问“凭什么”时怎么答；
3. **然后查第四节**：每个字母是什么、属于哪一类；
4. **填数**：常量查表、档系数一档一个、变化量现场测；
5. **要哪个对象的式子**，看第五节；**要哪一档的最简式**，看第三节。

**边界**：

- **同字母两义撞不上**：`D` 在活物档是扩散系数、社会档是需求总量——**一个对象只在一档；被判成死物／社会档，就不会走到活物那一档**，两义不在同一次计算里相遇。
- **数学域不需要额外判死量**：它连「散」都不参与，不在 `Λ` 的量程里；那一档只算个数。
- 本表是**定义与入口**，不是推导；**推导在账**，对不上以账为准。
