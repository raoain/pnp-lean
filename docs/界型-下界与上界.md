# 界型：我们能给下界，给不出上界

> 这一页只讲一件事：P vs NP 在这套里被归成哪一类问题，以及由此划出的边界。

## 四类猜想

| 型 | 问的是 | 例子 |
|---|---|---|
| **到达型** | 某条路能不能走到指定点 | 黎曼（`∃s: ζ(s)=0 ∧ Re(s)≠1/2`） |
| **覆盖型** | 是不是整支都可达 | 哥德巴赫（`∀n>2` 都有 `p+q`） |
| **穷举型** | 覆盖 + 可约（可化归到有限情形） | 四色定理 |
| **界型** | 被界的量落在一段里 | `abc`、孪生素数定量版、**P vs NP** |

## P vs NP 为什么是界型

- 它问的不是"某个解存不存在"，而是"**代价落在哪个量级**"——被界的是**代价**这个量；
- **界型的分工是写死的**：**下界可以推**（用信息量），**上界必须给出算法**（构造）——**我们没有上界，所以我们的边界就在这里**。

## 下界那一半（可推，且不依赖任何计算模型）

`M` 个候选；一次操作最多把候选分成 `w` 份；每次操作代价 `c`。

1. 区分 `M` 个候选，至少要 `log₂M` 比特信息（问题本身的信息量，与算法无关）；
2. 一次操作最多提供 `log₂w` 比特（`w` 是这次操作的分辨力）；
3. 因此任何算法——不要求它沿树走、不限定数据结构——都满足
   **步数 ≥ log₂M / log₂w = log_w M**，总代价 **`C ≥ c·⌈log_w M⌉`**。

这条界是**整体**的（对所有算法成立），不是"某一棵树上的计数"。

## 上界那一半（形状有，具体值缺）

**上界的形状我们有**：那条路写得很明确——每一步把候选集缩到 `1/w`，走 `log_w M` 步收成一条；`C = c·⌈log_w M⌉` 就是上界的形状。

**缺的是值**：每一类问题的 `w`（这一步实际能区分的份数）和 `c`（这一步的实际代价）**要实测填**。我们已填过五个域（见下），**P vs NP 那一类还没填**——所以缺的是"值"，不是"上界"。

## 所以这篇的立场

- **主张**：P vs NP 是界型问题；下界可用信息量给出；
- **不主张**：任何关于 P 与 NP 是否相等的结论；缺的是各类的 `w`、`c` 具体值，不是上界的形状；
- **可推翻点**：给出一个算法，其步数低于 `log_w M`（那就能推掉上面第 3 条）；或指出 `log₂M` 与 `log₂w` 的定义在此问题上不适用。
